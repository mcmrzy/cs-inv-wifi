## 视觉方向

用户最新澄清优先于上一版：逆变器居中，四个设备分别位于上(PV)、左(市电)、右(负载)、下(电池)。四条能流连接只允许水平/垂直线，不画斜线和折角。发电机移出主能流图；温度、频率、电流、负载比例、模式等转移到独立运行参数页。

发电机详情从参数页/设置入口进入：展示是否选为当前AC输入、已知运行状态，以及可明确归属的电压/电流等。无独立发电机功率字段时显示未计量，不把共用AC功率标记为独立发电机功率；原启动/停机GPIO尚未映射，仍不提供可执行启停按钮。

主屏保留PV/AC/负载功率和电池SOC、必要电压；方向由真实DSP状态驱动。上下键保留第二显示模式/参数入口，原有详细数据继续可达。

六类设备采用清晰线条图标，以中央逆变器为中心保留原拓扑。主屏不包裹文字卡片，靠设备位置、颜色与空白区建立层级。负载功率25px、SOC25px；PV17px、AC19px；辅助值10–11px。设置主值22px。全部画布为320×240，直接生成原始像素PNG供检查，放大图使用nearest，不以高分辨率模糊缩小掩盖小屏问题。

- 背景 #070b10，主字 #eff5fb，辅助 #91a0af。
- 活动能流 #72e0ac；PV #e6ba69；市电 #83bfff。
- 未活动设备及流线 #42505d；待机路径虚线。

## 页面

1. home-v2：电网/PV/发电机/逆变器/负载/电池；实际状态控制流线及方向。功率、SOC、电压、电流、频率、负载比例、温度、模式、时间、通信状态。主从状态和其他电压/电流留在主屏第二模式或详情，保留原入口，不删字段。
2. settings-v2：统一参数列表、明显焦点、名称和数值对齐。草稿编辑须显示修改状态；Sending/Confirmed/Timeout区分，不能静态显示已成功。图中DSP readback confirmed只是成功状态示例。
3. battery-v2：SOC/总压/单体差值，4×4单体列表、最小/最大标记。温度/容量等无协议支持的字段继续未知。图中单体和汇总为示例，不用于实际计算；运行时必须用一份一致快照。
4. alarms-v2：当前告警列表及详情入口，图标+文字+颜色区分严重程度。图中文字是样式示例，固件实际接原告警表；不虚构新的故障码。长文本使用详情或分页，不截断关键说明。

## 操作与运行约束

六键继续使用现有导航；清楚呈现选择、修改、确认及返回。离线显示OFFLINE/--，不使用示例填充。未经协议支持的参数保持只读。当前接线和GPIO4恒低策略不因视觉改版改变。

渲染器与DSP写参数状态机分开。0.2.3硬件SPI+DMA先由用户验证；图形版采用局部刷新、小缓冲。LVGL可作为实现选项，是否采用由实际内存/刷新量验证决定；不能承诺加入LVGL就提高速度。关键验收包括通信同时运行、按键及时发声、网络/OTA内存峰值及实机刷新。
