# 统一字体修复：2026-10-08

用户指出v0.4.2大量文字字体及大小不一致。
已确认根因：small表以中文16px/西文14px生成；large表仅有数字标点，W/V等单位回退正文，导致同一行混排；字框高度与部分场景的条带可见性检查不一致。

修复：
- 正文、辅助标签、英文、参数数字、单位统一官方Noto Sans CJK SC Medium原生16px，一张408字表、20px统一字框及15px固定基线；12/14历史请求均映射正文，不再按语言分流。
- 主数值24/28px的单位和空格补齐；数字等宽；中文或普通文字设置整行选正文，测量与绘制使用相同决策。
- 页脚移到y221、电池下部留出间距；配置及BMS可见性边界按真实字框修复。
- Logo图形维持品牌原图（不是字体）；启动版本文字兼容新字框。
- 回归先证明small字模一致性失败，修复后通过；新增大数值单位高度一致、整行文字回退宽度一致验证。116页面全帧/16行条带与守卫测试通过。
