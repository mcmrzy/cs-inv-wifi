# CSERGY 控制器 UI / 六键交互重构草案

2026-10-12。状态：设计预览，等待用户确认后实施；基于0.4.4-fixed-sn。所有预览使用模拟值，不连接设备。

## 设计选择

推荐：四个常用页＋六组设置，以状态/信息层级和可预测按键为重点。
备选一：保留旧菜单只换皮肤，迁移最小，但隐藏双击和跳转习惯仍在。
备选二：LVGL全框架迁移，组件能力更多，但ESP32-C3内存、刷新和现有功能回归成本更大。
建议继续现有RGB565条带绘制：圆角卡片、色带、统一字库可实现；是否有必要引入LVGL取决于实际效果与资源，不把框架名称当作产品质量。

## 视觉约定

320×240横屏，不伪装触摸屏。正文/西文/标签/参数/单位统一Noto Sans CJK SC Medium16px；大值24/28px，同一数值与单位同字号。固定基线，数字等宽，中文英文墨迹差异尊重原字形。标题栏25px、内容区域约188px、操作栏23px。选中元素除颜色还有底色/色带，离线和告警有明确文字。

深色：深蓝底、蓝色结构、白色主文字；光伏金、市电蓝、负载橙、电池绿、逆变器紫。浅色：浅蓝底、白色卡片、深蓝主文字，同类来源保持一致色相。常规页面不使用灰色；斜视发淡不通过随机gamma参数补偿。

能流页保留上光伏、左市电、右负载、下电池、中逆变器。横平竖直连线。方向只取已有明确功率/电流状态，未知显示断续/静态状态，不能把“输入有效”当“正在供电”。能流动效用小范围标记更新，不连续全屏刷新；进入页面、按键反馈和真实数据更新分别触发重绘。

## 导航与按键

- 常用页：能流、电池、运行参数、告警。左右单击切页；确认进入本页详情或设置；返回回概览。每页顶部显示标题，底部显示本页有效操作。
- 设置入口：输入与输出、充电、电池与均衡、发电机、系统、高级参数。方向键选卡片，确认进入。
- 返回保留上一层选择和列表位置；返回不会越过一级跳到首页。取消编辑先恢复本页草稿，不改设备值。
- 确认/返回只处理按下边沿，按住不连发；方向键列表可重复、编辑可连调。现有触摸帧协议及安静窗口保留。
- 编辑进入时不修改数值；左右一步、上下十步，但枚举选项按一项、范围严格夹紧，复杂特殊参数保持原校验。
- 按键声仅一次按下反馈；连续调整可降低重复蜂鸣，避免长按持续响。写入确认是文字状态，不靠声音判断。
- 删除隐藏组合键触发重启/复位，维护操作放系统菜单并二次确认；不改变逆变器保护策略。

## 修改参数

浏览 → 确认进入编辑 → 当前值/拟修改值 → 确认进入复核 → 新一次确认提交 → DSP回读匹配才成功。
编辑期间保留草稿、不被轮询覆盖。保存超时/拒绝保留拟修改值和原因，可重试或取消；未确认不得显示成功。提交时重新检查在线、可写、已知当前值、合法范围及相关前提。离线禁止DSP写入，本地外观/声音/时间等按已有允许策略继续。

方向键重复事件不得触发确认/返回；切页面必须等待按下边沿。通信 pending 期间禁止同参数重复提交；处理确认/超时状态后才能新提交。必须保留现有协议和DSP确认处理，不能通过UI假设成功。

## 原型范围与限制

index.html可以用按钮/键盘体验四常用页、六组入口、示例充电电流编辑、复核、模拟DSP确认/超时、离线锁定和主题语言。截图为独立设计绘制，不是新固件实际输出。
代表参数只模拟市电充电流0–60 A。部分分组暂复用代表设置页；84参数总览只展示代表字段；单体使用模拟值；告警操作仅演示提示。不能把此原型当作全部功能实现完成。

## 实施边界与验证门槛

1. 保留当前可烧录0.4.4发布产物，UI新模块和状态机增量替换，不覆盖其它工程。
2. 先重构导航/历史位置/编辑复核状态机及按下-重复语义，再实现场景/本地化/布局；业务通信职责保持原分层。
3. 关键行为测试：全84参数可达、离线与只读拒绝、枚举/特殊前提/边界、草稿保持、复核取消、按住确认不能连过页面、保存超时可重试、回读成功才能生效、时间合法性、恢复与外观取消/保存失败。
4. 中英深浅所有页面由实际C渲染导出，检查无缺字、不截单位、不混字号；全帧与16行条带一致、守卫保护。
5. ESP-IDF构建及4MB分段/哈希校验；提供手动烧录文件，未授权不自动烧录。
6. 实屏验收：可读性、按键响应、刷新时长/闪烁、蜂鸣器与长时间运行。页面动画和性能必须报告测量，不宣称未经验证的帧率。
