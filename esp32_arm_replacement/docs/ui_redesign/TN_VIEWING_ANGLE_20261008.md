# 斜视发淡：本轮定位与修正

用户澄清：正面看并非明显发灰，只有斜着看时明显变淡。用户提供的 `SP-TFT028F276(1).pdf` 第 4 个 PDF 页面（印刷页码 -3-）列出 TN、240(RGB)×320、12:00 观察方向及 ST7789P3；没有给出模块推荐初始化代码或伽马寄存器表，光学规格页也未填入对比度典型值。

结合这一观察，现象主要符合 TN 观察角度的影响。不能把原 ARM 寄存器值相同当成对比度正确的证据，也不能保证默认初始化在斜视时更清楚。软件可增强文字和数值辨识，无法保证消除 TN 面板的视角依赖。

0.3.2 撤回 0.3.1 启用原 ARM 模拟电源/伽马的变更，恢复复位后默认参数，不试调未知 VCOM/驱动电压。重要功率数值使用实色白，保留饱和分类标签、设备图标和能流颜色及二值半粗字体。GPIO4 CS 恒低、SPI模式/频率和其他功能不变。

验收仍需实机：相同亮度与观察方向对比 0.3.1 和 0.3.2；启动日志 0.3.2 应出现 LCD MINIMAL_INIT，不能出现 LCD ARM_PROFILE。主机画面和镜像验证不证明斜視效果。
