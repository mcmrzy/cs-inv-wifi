# DSP 默认参数恢复修复

旧逻辑仅在参数记录不存在时初始化原 ARM 默认参数。已有记录损坏、SN 不匹配、版本或内容校验失败时直接退出，导致 `hold=0x08`，无法发送 `00/01/02` 或正常轮询。

启动时现在执行以下规则：

- 已有有效参数：保留全部设置与 revision，不额外写入 Flash。
- 缺失、损坏、SN 不匹配、格式或参数范围错误、截断或超长记录：重新生成原 ARM 默认三包，绑定当前 SN，完整保存并提交后启用。
- 恢复成功后沿用启动同步流程，发送 `00→01→02`，再轮询 `03/04`。
- 存储读写故障仍明确报错。保存失败时不启用未持久化的默认参数，不把 RAM 参数误报为 durable。
- 管理员读取接口仍严格校验原记录；自动恢复只发生在启动初始化。

默认值保持原 ARM 来源不变，包括 230V/50Hz、电池类型 1、最大市电充电 60A、总充电 140A、发电机平衡关闭。这些默认值不是本机电池配置的自动识别结果。

设备验收：启动日志应显示参数恢复及保存成功、`DSP persistent params=READY`；随后检查 `hold=0x00`、`DSP sync ready=1 durable=1`、发送计数增加和 `03/04` 持续更新。重新上电后应直接使用已恢复记录，保留用户后续修改的设置。逆变输出须另行进行实机确认。

本文件更新了旧版 `DSP_DEFAULTS_V0613.md` 中“损坏或不同 SN 不自动替换”的启动策略。
