# DSP启动参数同步与固定短包的源码复现

固件0.6.12-dsp-sync，2026-10-14。

## 已定位的软件路径

用户提供的ArmComm.c（SHA256 af623ada04cb4165058b94fb942d22cbdbea5af26d580b15aae3b3fbb7b8a121）为DSP侧实现。
03/04处理先发22/69字节回复，尾部在00/01/02未全部收齐且QueryParamDelay为0时又发5字节请求。
ScibSendData直接覆盖共享ScibTxBuf，更新长度但不检查发送忙/不重置索引；TX ISR异步读取。
如果第一次已发送头两字节，第二次覆盖后实际余下变为00 21 90，得到日志中的01 12/41 00 21 90。
QueryParamDelay初始10，仅在收到命令后递减，没有重置，与启动前几帧正常、随后混包吻合。
本地提取真实发送函数及参数分支的交错测试精确复现两组字节。尚未确认实机DSP部署版本，故不把代码模型当设备实测。

之前优先怀疑线路/接收字节损坏的方向缺少这份DSP源码，现已转向完整初始化握手。输入上拉配置保留，但不把它当既证根因。

## 本版流程

1. 读取SN绑定的完整持久参数组。有效时启动依次发送00(25B)、01(23B)、02(16B)，每110ms时隙最多一帧，再开始03/04。
2. 缺少/损坏/异机参数、保存失败或同步待发送时暂停普通查询，UART仍继续接收并计数；不会套未知默认值触发DSP混包。
3. CRC正确的5B同步请求只设置待发位，优先级00→01→02。重复请求合并，发送失败下一槽重试。
4. 已复现的01 12/41 cmd CRC短候选仅作为collision_hint触发可信已保存参数的重新同步，至少3秒间隔；它不计入有效帧，也不提供参数值。
5. 管理员通过USB一次导入三个完整原始ARM回包，校验SN、全部长度/CRC和参数范围，单个88B版本化CRC记录保存到NVS。
   保存失败不启用新RAM参数；同机重启恢复。没有拆成三次导入或三个NVS键。
6. 现有控制写入须完整配对字段通过25回读确认，再只更新该写命令涉及的持久字段；其他标志位、并机和发电机参数不改。
   运行时25中的临时电流限制不会覆盖用户上限。Flash操作由主任务/管理员任务执行，UART owner不格式化、不写Flash。

00不含bulk均充电压，保持原协议；02发电机/01完整模式字等不能从25还原。
bulk单项运行写入不包含在本版三包持久恢复中；不会把它冒充float或声称bulk重启恢复。
跨电池类型通过完整新参数组导入，清旧可写快照后等待新的25；不沿用旧type的阈值。
这份ArmComm.c未包含25发送路径，因此25确认能力还取决于实际DSP固件是否支持之前ARM源码的回读扩展。
回复发送成功只表示UART提交成功，不等于DSP参数已应用或GetArmParamReady实测为1。

## 初始参数来源

旧ARM开机从USERFLASH ParamFlash_Init及SysParamFlash_Init恢复inverterParam1和SysParam；三个回包取这些实际值。
源码出厂初始化只有持久记录无效才使用，不能据此推断当前设备Flash内容。
ESP无法从用户提供的源码目录读取物理ARM芯片的保存值；首次使用需要原ARM实际回包或经明确确认的完整工厂设置。
本版没有捆绑一套自动生效的测试参数。新板没有参数时会显示MISSING并停止DSP查询；WiFi/MQTT和诊断仍工作。

## 导入、导出与验收

准备JSON，字段为sn、cmd00、cmd01、cmd02，后三项是对应原ARM TX帧的完整十六进制字符串（含CRC）。
运行tools/dsp_params_import.py 参数文件，仅校验格式/CRC；加--port COM16时会询问既有管理员密码，核对设备SN后导入。
不通过命令行参数传密码。固件再检查范围，成功后工具读取dsp_params并逐包比较；读回变化/失败不冒充成功。
串口dsp_params可直接查看ready、durable及三个帧，status显示DSP_SYNC回复计数。

只更新device/app.bin，保留SN/PIN/WiFi及DSP参数NVS。整片4MB镜像覆盖这些配置，不用于保留设置的升级。
升级后确认版本，完成一次同机参数导入，再观察DSP sync ready=1 durable=1、replies增加、03/04持续刷新。
保持供电至少2分钟，再分别重启ESP/DSP验证参数重发和掉线恢复，并逐字段对照真实显示。
旧的5字节错误候选不能靠补字节/放宽CRC当成合法命令。BMS没有数据仍不发送虚构05/06。

测试覆盖实际DSP发送竞争、三包字节、SN绑定/损坏/短组拒绝、NVS失败、认证和秘密清理、完整写回匹配、真实owner优先同步、缺参数不查询、重发与混包提示。
本地回归和构建不替代设备长期通信、参数应用或DSP/BMS OTA验收；直连OTA仍关闭。
