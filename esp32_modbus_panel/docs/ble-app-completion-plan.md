# Modbus 面板 App 蓝牙完善计划

目标是在手机断网时，用 App 操作已连接的 2KU、3KU、6KU、12KU 面板。固件依据已确认的机型、实际回读与当前运行状态决定读写权限。

1. 复用现有蓝牙会话和分包。面板声明支持原生参数接口，App 用连接中的设备 SN 选择会话。
2. 从 Modbus 快照定期生成蓝牙监测数据。支持运行状态、告警、独立电池及单体电压，明确数据更新时间与断联状态。
3. 从固件目录读取分类、当前值、可选值和限制。写入检查通信配置代次，开关机复用面板的运行状态限制。
4. 区分读回一致、设备已受理、读回不符、拒绝和超时。App 继续刷新实际值，旧固件和云端设备保留现有行为。
5. 增加显示、声音、日期和时区、电池连接及通信诊断。复用现有绑定、Wi-Fi 配网和 BLE 升级。对支持的 BMS，提供充电电流上限、充电电压和放电保护电压的建议值，采用建议时再次检查电池与逆变器状态。
6. 验证四种机型、未知机型、断线、并发写入、读回延迟和小 MTU。构建面板和 App，实机验收用断网手机逐项核对。

未提供寄存器或机型禁止的功能，在 App 显示固件返回的限制。生产校准、出厂身份写入和恢复出厂仍在设备维护流程内。自定义电池的参数按实际协议和机型范围分别保存。

## 实机验收

- 在 2KU、3KU、6KU、12KU 上分别确认机型，关闭手机网络并保留蓝牙，检查实时电压、电流、功率、SOC 和告警。
- 每款选择一个设备支持且当前状态允许调整的参数，保存后核对 App 的实际值和逆变器回读，随后恢复测试前的值。另检查拒绝、超时和断线后的表现。
- 在测试负载下验证开机、关机和停用远程开关机。断开 BMS 后核对无效值处理，接入 CSERGY 后核对待机时的建议值和过期保护。
- 检查显示与声音配置保存、配网返回后重连、串口地址扫描及已下载固件的本地升级。面板天气城市设置继续使用屏幕入口。
