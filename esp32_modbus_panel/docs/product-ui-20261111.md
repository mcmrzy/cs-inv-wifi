# 面板日常使用改版

适用 2KU、3KU、6KU、12KU，沿用 320×240 横屏与六键输入。

- 主菜单为运行参数、逆变器设置、开关机、故障告警、辅助设置。
- 逆变器设置直接进入图示分类，含全部参数入口。移除普通用户路径的常用/更多分层。分类后以单项卡片浏览，确认编辑，方向键调节，返回取消。始终显示当前值、目标值和允许操作的按键。
- 运行参数为按电网、电池、光伏、温度、负载等划分的整屏仪表。用原有插画建立视觉锚点，功率/电量优先，辅助数值用卡片呈现。不存在的数据为破折号，历史数据明确标记。
- BMS 统一使用面板 BBJ/CSERGY 实际采集结果。界面仅显示电池连接状态、数据、单体与连接设置，不向用户呈现内部拓扑。原逆变器 BMS 哨兵值不得作为有效测量。
- LED 使用 0–100% 调节，底层保留 0–255 精度。无源蜂鸣器使用 4kHz PWM，固定70ms，响度分关闭/低/中/高，最大50%占空比。旧设置迁移保留关闭状态。
- 设置由面板自动读回目标配置或文档明确的替代地址/使能位；文档定义的完成标志可报告逆变器已接受。拒绝、数值不符或通信超时给出具体结果，禁止伪报生效，也不要求用户自行检查机器。
- 电压、电流、SOC 来自面板采集。CSERGY 可通过 FC03 读取电池充电电流上限、充电电压上限和放电电压下限，按自定义电池的最大充电电流、恒压点和电池关机点带入建议值。只在待机、数据新鲜、机型与阈值约束通过后带入，用户确认后逐项写入并检查结果。电池型号栏保留检测到的 BBJ/CSERGY 标识。BBJ 的保护阈值读法未验证时走手动设置。

验证覆盖六键浏览/返回/取消、当前和目标值、自动确认、缺失/哨兵/历史数据、BMS两种协议、亮度百分比边界、固定70ms及PWM资源独立。最终编译并检查实际固件渲染与OTA空间。
