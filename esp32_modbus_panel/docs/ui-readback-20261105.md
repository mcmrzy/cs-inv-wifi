# 0.4.6 界面与设置读回

协议依据：`CVTE-INV-Modbus地址表（外发）V1.27.xlsx` 的 WF_UserSet!I2 明确规定：一次只设置一项，间隔大于500ms，写后回读65535表示设置成功。

固件保持600ms写间隔、每轮至多一笔请求、3秒确认期限及不自动重发。写应答后用03查询完成标记和独立设置值；即使标记未返回FFFF或该地址不支持读取，仍尝试独立设置值。只有独立读取匹配目标才确认数值已生效；同址返回目标本身不能冒充独立确认。FFFF仍按协议表示完成。

打开或翻页时主动查询五个可见设置，编辑页查询该单项。先用独立设置地址；失败/无法解码时退回该项读写地址。返回FFFF、超时、不支持读取和异常分别显示；读写地址返回的数值明确标为设备返回值。可用返回值初始化草稿，不能用于独立确认或无变化写入抑制。该缓存仅五条、跟随设备上下文清空，恢复连接后立即刷新；查询不修改写命令序号或结果。

补充字库改为20px字框与统一基线，逗号像素从上部0～6行恢复到下部11～17行。所有正文与数字字号均做C解码像素摘要校验，LVGL字形打包逐像素比较；压缩所有字号并复用512字节解码空间，移除原有独立打包缓冲。界面保留房屋素材，校正页眉、单位和读数的对齐，历史值不再依赖尾随星号。

原有频率、优先级、工作模式、电池低压、均衡电压、延时、双输出电压及功能位读回保留。电池关机点、转市电/转电池电压等没有独立地址的项目，使用03同址查询。有可解码的数值时显示设备返回值；返回完成标记时显示设备未提供当前值。

界面采用实际固件的LVGL渲染，保留已有按键导航和单项写入流程。页脚按键提示共用一次绘制回调，减少常驻标签对象和内存池碎片。选中条有短暂宽度反馈，能流仅在新鲜在线数据和实际功率非零时运动。局部缓冲为320×16，SPI40MHz，切页不复位。LCD在首帧绘制成功后开启。

主机验证覆盖：输出/恒压/浮充读回一致、不一致、错误电压族、时间换算、完成标记、超时、拒绝、单次写、持续采样、断联取消草稿及恢复；真实LVGL渲染电压编辑与不一致结果。主机示例画面和测试通过不代表实板电压已修改或重启后已保存。

已有BMS完整帧筛选及无发送后清缓存逻辑保留。本轮不宣称修复已有TLS内存不足或BMS上电后偶发无响应；它们仍需要独立的实机证据。
