# 0.4.29 CHG 零电流方向修复

用户反馈屏幕显示电池向逆变器放电，CHG 为绿色呼吸，未提供本次变绿时的 CHG 原始记录。已确认代码中存在一种可复现的错误路径：电流为零、终端仍报告充电，能流不满足独占放电时直接回退为绿色呼吸。

3KU 原协议表 WF_Simplify 明确规定 0081 为有符号 0.1A、0085 为有符号 1W，均为正放电、负充电。原实现未使用有符号功率，遗漏小功率场景的方向依据。

修复后的优先级如下。

- 已知低电、保护或限流仍显示黄色，不被方向覆盖。
- 新鲜的非零电流按原规则判断，保留正负 0.1A 的真实反转。
- 3KU 电流为零时，可使用与电流具有相同采集时间的新鲜功率符号。
- 零电流、无可用功率方向时，仅使用新鲜的单向能流；同时启用充放电路径不视为独占充电。
- 终端充电标志单独出现时不再亮绿色呼吸。充满仍按原来的绿色常亮规则处理。
- 电流缺失或过期时保持原有保护，不凭缓存状态亮绿灯。

回归包含四机型、3W 放电与 -3W 充电、零电流充电标志冲突、功率与电流采集时间不一致、正负 0.1A、过期数据和充满状态。新增用例在修改前能触发错误，修改后通过。

CHG 变化日志增加 power_raw。仍需用实板变色时的 current_raw、power_raw、flow 和 fresh 对照确认，此修复不能证明未记录的现场负电流或其他输入没有问题。
