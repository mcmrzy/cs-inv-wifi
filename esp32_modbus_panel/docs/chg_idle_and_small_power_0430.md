# 0.4.30 电池空闲、功率与缓存修复

用户补充 CHG 熄灭时首页显示 0 W，日志运行模式为 0002（待机）。0.4.29 取消单凭充电标志亮绿色后，没有区分已连接空闲与未连接，导致零电流、零功率时熄灭。仅凭现有日志不能证明当时机器真实功耗为零或有未报告的微小功率。

## 灯态

- 新鲜数据确认电池已连接且无充放电方向：蓝色常亮。
- 实测放电：蓝色呼吸。实测充电：绿色呼吸。
- 充满且没有放电能流：绿色常亮。
- 低电、限流或相应保护：黄色呼吸。
- 电池未接、状态缺失或电流过期仍不伪造在线或充放电状态。

panel_battery_direction 为灯和测量映射共享符号判定。3KU 电流为零时，使用同一采集时间的新鲜有符号功率。映射保留实测瓦数和 SysStatus 方向，不编造电流。首页电流为零时可使用单向的实测充/放电功率，非零电流时保留原有显示；对应的小功率能流动画仍可运行。

## 缓存

用户日志中的告警已获得 PUBACK 且 pending=0，但遥测缓存每十秒报告读取失败。检查 ESP-IDF 5.5.4 SPIFFS VFS 注册发现支持 stat、未实现 access；后者返回 ENOSYS。make_filename 使用 access 检查 c 批次存在性，会错误回退到不存在的 b 文件。

改用 stat，不重写或清空旧缓存。回归将 access 模拟为 ENOSYS，修改前真实读盘用例失败，修改后 c 与 b 两类批次均可读取，临时文件仍被排除。所有文件内容保留。

## 验证边界

回归覆盖四机型灯态、待机零功率、0A/3W 放电、0A/1W 充电、旧充满标志、数据过期、首页瓦数与能流，以及实际文件提交与 SPIFFS 接口兼容。实机仍需确认当前原始功率、灯态和缓存补传完成情况。
