# ESP32-C3 Modbus 完整屏幕控制器

当前版本 **0.4.31-modbus-full**，待四款销售机型实板验收。主菜单有运行参数、逆变器设置、开关机、故障告警、辅助设置五个入口。逆变器功能使用实际 Modbus 数据和参数目录。支持 Wi-Fi STA、BLE、MQTT、绑定、缓存及 ESP/BMS OTA。

0.4.30 区分电池在线空闲与实际充放电：在线零功率蓝色常亮，放电蓝色呼吸，充电绿色呼吸。灯与测量共用方向判定，保留 3KU 电流归零时的实测瓦数；首页小功率不再只依赖 V×I。分类图标、参数卡片和文字对齐重新整理。缓存存在性检查改用 SPIFFS 支持的 stat，恢复原有 c 批次读取。

0.4.29 修复 CHG 在电流归零时被充电状态标志误判为绿色呼吸。3KU 使用同一采集批次的有符号电池功率辅助判断，正功率放电为蓝色、负功率充电为绿色。仅有充电终端标志时不再亮绿色呼吸，CHG 日志补充原始电池功率。

0.4.28 修复蓝牙低内存启动失败后 MQTT 被反复暂停、重连窗口被蓝牙调度等待关闭的问题。释放 MQTT 后仍不满足蓝牙门槛时立即恢复云端，自动尝试退避 5 分钟；重新进入手机连接页面可显式重试。蓝牙内存保护门槛不降低。

0.4.27 修复联网后离线补传任务栈溢出重启。压缩临时缓冲改为按需分配，补传使用 SDK 异步出队发送，任务栈增至 6 KB，保留精确 PUBACK 确认和低栈余量诊断。

0.4.26 补齐 V3 运行快照断网保存与原时间续传，单条容量 1023 字节，采用批内无损压缩；每 5 条或约 10 秒提交。保护旧缓存和挂载失败分区。云服务配套更新历史时间处理，避免补传影响实时状态。详见 [离线保存与续传](docs/offline_storage.md)。

0.4.25 随 App 语言返回中英文参数名、设置选项和运行参数。面板设置列表上下逐项选，左右整页翻。开关机菜单增加可选的停用远程开关机。

0.4.24 新增 3KU 云告警、恢复及断网补报。云服务需同步发布告警字典，Web 和 App 使用服务端提供的告警名称。分段工站包可在烧录前核验产品标识和镜像哈希。详见 [告警上报与验收](docs/alarm_upload.md)。

0.4.23 加入 Modbus 面板蓝牙接口。App 按面板提供的目录读写设置、控制开关机、查看运行数据、告警和 BMS，并可配置显示、声音和通信。蓝牙快照独立按秒刷新。需要配套 App，旧版手机端仍使用原有接口。详见 [App 蓝牙完善计划](docs/ble-app-completion-plan.md)。

0.4.22 将运行数据和参数编辑改为图示卡片，所有参数分类直接在逆变器设置中可见。LED 亮度按百分比调节；无源蜂鸣器固定鸣叫 70 ms，可设为关闭、低、中、高。电池页显示识别到的电池协议标识和实时数据，无有效数据时显示连接状态。

CSERGY 的充电与保护设置可以从电池读取建议值。选择自定义电池并让逆变器处于待机后，进入电池页 → 确认 → 充电与保护设置。最大充电电流、恒压点和电池关机点在电池值有效且符合机型限制时，打开编辑会带入建议值；按确认键逐项保存。BBJ 缺少已验证的完整保护参数，仍可手动设置。

0.4.21 修复 CHG 小电流放电误亮绿灯。有效电流按正放电、负充电判断，包括 ±0.1A。电流取整为零时，明确的单向放电能流优先于充电或充满标志。电流未收到或过期时，不再单靠电池状态点亮充电或充满灯。灯色或呼吸状态变化时，串口输出 `panel_led CHG` 及状态、电流原始值，供实机核对。

0.4.20 首页快捷键直接写明「模式」和「市电」，有当前告警时突出告警入口。告警页分开显示当前与上次条数，数据不完整时提示待确认。参数列表在进入编辑前显示限制和原因，选定有效值后才提示保存。显示设置保存失败会恢复已保存的显示效果，保留本次调整供再次确认。

0.4.19 将首页重排为四路能源仪表盘。房屋插画位于中央，电网、光伏、电池和负载以统一卡片呈现，支持明暗主题。通信中断时保留上次数据并暂停能流动画。菜单、参数编辑和告警统一采用对应的状态样式。

0.4.18 保留房屋和设备插画，重新调整明暗主题、主菜单选中态和设置页的数值对齐。设备插画使用更细的色阶和边缘透明度。首页用文字和颜色区分实时、上次数据与等待数据，只有实时能流显示动画。拟设值、当前值和回读结果各自使用清晰的视觉层级。中英文字库采用无损编码以缩减固件体积。

面板设置 → 显示设置可保存 WS2812 亮度（0～255，默认 24）和蜂鸣时长（关闭、40、70、120 ms，默认 70 ms）。GPIO10 使用开关驱动，响度由硬件决定。背光在新机和恢复本机默认时为 100%，已有的背光设置保留。

通用 App 支持 **3KU（24 V）**。型号候选码为 `0x50`，在通信设置中按铭牌确认后可编辑 3KU 参数。市电功率按 `0x005E - 0x0053` 计算，光伏总功率取 PV1 和 PV2 之和，使用 3KU 电池状态、温度和 BMS 电流单位。面板、本地蓝牙和云告警使用 3KU 对应的位定义。

3KU 输出频率仅在待机或旁路可改，输出电压另允许电池逆变模式。市电充电电流按 1 A 调整，先使用协议所列 40 A 和 60 A 版本的共同范围 2–40 A。并机模式、并机 ID、发电机额定与最大功率、发电机恢复功率和 BMS Pack ID 保留只读。3KU 的 FEL 电池类型在协议读写说明里存在冲突，依赖其化学类型的参数继续受限。

通用固件面向 2KU、3KU、6KU 和 12KU。V1.27 机型按表内对应列校验最大放电电流、市电电压阈值和 12KU 并机选项。低 SOC 告警适用 2KU。旧版本保存的其他机型会回到自动待确认，原有从机地址、波特率和校验方式继续使用。设置回读只使用协议能明确对应的地址和编码。

IPS 板验证构建使用 ST7789P3 例程的电源和 Gamma 参数，320×240 横屏、RGB565、`INVON`。GPIO10 为高有效蜂鸣器，按键按下短响一次，长按连发不重复响。故障新出现时按面板告警和蜂鸣设置短响。WS2812 DIN 接 GPIO9，串行顺序为 ALM、NET、CHG、RUN。GPIO9 同时是 BOOT 引脚，硬件需保留上拉，固件在进入应用后才启用灯带输出。

本程序通过 GPIO1/0 连接**已实现 CVTE V1.27 Modbus 的逆变器主控**，不能连接只接受旧 direct 私有协议的 DSP 接口。

## 面板按键与查看路径

- 首页按确认进入主菜单，按上或下打开上一张或下一张运行数据页。左键直达告警，右键打开独立 RS485 电池 BMS；左右翻页查看总览和两页单体电压。未收到数据时不显示零值，超过5秒未更新时明确标记断联与上次数据，恢复后显示实时数据。
- 主菜单上下选择，确认打开，返回退一层。运行数据从目录按设备类别查看。详情页可以上下翻页，也可按确认回到目录。数值与单位放在右列，`--` 表示缺数据，`*` 标记旧值。
- 常用设置直接显示输出频率、输出优先级、运行模式、充电优先级。选中后按左右键修改，再按一次确认提交。列表底部的「更多逆变器设置」按用途列出其他参数。开关机保留独立确认。
- 面板使用 LVGL 8.4。默认黑底蓝色，保留浅色和中英文切换。首页能流、按键选中和写入等待按局部区域刷新，继续使用现有 16 行 RGB565 缓冲和 40 MHz SPI。
- MQTT 在现有 `cs_inv/{SN}/info`（QoS 1、不保留）通道报告已识别的 `2KU`（沿用云端型号编码 `PWR2KH12H1`）、`3KU`、`6KU` 或 `12KU`。只有实际写入的序列号和新鲜一致的 Modbus 识别码可用于型号绑定，首次发布型号后补发一次。没有已确认的 DSP 版本和额定功率时省略这两个字段。
- 本机显示设置用左右键预览，确认保存，返回放弃预览。保存失败时恢复此前的显示。

## 通信诊断

正常固件默认全局Warning日志；本版单独开放panel_bus和modbus_direct的Info日志，无需打开全部调试。启动即打印实际UART0地址/波特率/校验，链路状态改变或每10秒输出一次诊断。

| 日志 | 含义 |
| --- | --- |
| INV_LINK ONLINE | 当前配置地址的0042运行状态在5秒内收到有效匹配应答，状态值0–10 |
| INV_LINK VALID_READ_NO_STATUS | 有近期有效寄存器读应答，但运行状态尚不可用；不是完全没有通信 |
| INV_LINK MODBUS_EXCEPTION | 收到有效Modbus异常应答；查看INV_RX的寄存器和异常码 |
| INV_LINK RX_UNMATCHED | UART0收到字节，但未组成地址/功能/长度/CRC均匹配的本次应答；查看head原始摘要 |
| INV_LINK NO_RESPONSE | 未获得近期有效应答；INV_RX若为NO_RX且rx_bytes=0，表示该失败请求没有收到字节 |
| INV_LINK PAUSED / SCANNING | OTA等维护暂停 / 正在只读搜索地址，不直接作为主控掉线判断 |
| INV_DATA READY | 完整运行数据满足本地转换与2秒新鲜度条件；不代表已经上传或云端收到 |
| INV_DATA MISSING / STALE / INVALID | 完整数据缺失、过期或数值不合法；problem_reg指出首个阻塞寄存器，raw和age_ms辅助判断 |

INV_RX记录最近失败请求的目标地址、功能码、起始寄存器、数量、异常码、收到字节数、距今时间及最多24字节的head。数据缺失时用FFFF和4294967295表示不可用的原始值/年龄，不能当作有效测量。

BMS警告明确标注UART1 TX21/RX20，并输出最多24字节原始摘要。BMS收到7字节不等于有效BMS报文，也不证明UART0已连接逆变器。屏幕LCD_DIAG只记录显示任务和SPI状态。

原TELE模块的旧DSP命名保留，但其链路可达时间现根据有效0042应答更新，与完整遥测是否齐备分开。升级后观察约10秒，提供INV_LINK、INV_RX、INV_DATA及BMS head即可继续定位；不会自动改地址、波特率或执行写操作。

- 修改地址、波特率、校验或机型并保存成功后，清空旧逆变器测量、告警、设置和OTA诊断缓存；完整首页也清掉旧画面数据。保存失败保持原上下文。
- 电量累计保留控制器历史总量，切换通信上下文时重新建立积分采样基线，避免把前后设备的采样拼在一起。BMS链路和独立数据不重置。
- 保持原4MB双OTA分区和CS-MB-PANEL产品标识，可由同身份档0.2.0的ESP OTA升级；首次完整镜像安装仍会清空持久配置。

## 操作

1. 默认显示首页能量流，确认进入五项普通主菜单，首页左键进入故障告警、右键进入独立RS485电池BMS；逆变器报告的BMS数据仍在运行参数中。
2. **参数设置**直接进入实际协议参数分类；**开关机**为独立复核入口。本机设置包括显示、时间、信息、重启、恢复本机设置、升级和手机连接。
3. **维护诊断→逆变器通信设置**设置地址、串口、机型及只读搜索。当前日志中的设备地址为1；其他机器无响应时执行搜索，找到后手动保存地址。
4. 0038/0039 提供候选机型。根据铭牌手动确认 2KU、3KU、6KU 或 12KU 后，开放相应机型设置。
5. 参数调好后按一次确认发送，返回可取消草稿。开关机另行确认。
6. 通信诊断左右切换，读取主控OTA状态；该页面只查询，不进入Boot、不发送固件。

上电不会自动修改逆变器设置或回放私有默认参数。Modbus单任务独占UART0，BMS单任务独占UART1。

## 数据与写入结果

每次只写一个参数，功能码0x10，写间隔至少600ms。超时不自动重发；区分写应答、处理完成、实际值已回读、失败和结果未知。FFFF只是处理/空闲标记，不能显示成当前值。

本地Modbus页没有数据为`--`，旧值加星号；完整direct首页沿用原显示缓存策略。遥测只在所需实际字段齐备且新鲜时转换，原协议保留字段仍为零。电池电流正为放电、负为充电，逆变器SOC按0.1%换算，独立BMS沿用原协议。

V1.27 写入应答后，同址通过03读到 FFFF 表示设置成功。如果当前机型没有独立当前值地址，面板提示“设置成功”，MQTT 使用既有的 submitted 阶段，BLE 返回 PROTOCOL_ACCEPTED 并标记已提交。若配置了独立读回但未核对成功，仍返回 VALUE_UNCONFIRMED（-22）。没有当前值映射时保持未知，不用上次下发值替代。

协议对 0038/0039 的机型定义存在冲突。02A0 输出电压设置值采用已知电压枚举核对。故障、初始化、测试、升级期间禁止设置。

## 固件包和实板验收
