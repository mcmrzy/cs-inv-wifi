# ESP32-C2 ESP-IDF 移植方案

> 源项目: cs-inv-wifi-main (ESP32-C3 + Arduino/PlatformIO)
> 目标: ESP32-C2 + ESP-IDF v5.x

---

## 1. 新项目结构

在项目根目录下创建 `esp32c2_idf/` 文件夹：

```
esp32c2_idf/
├── CMakeLists.txt              # 顶层 CMake
├── sdkconfig.defaults          # ESP-IDF 默认配置
├── partitions.csv              # OTA 双分区表
├── main/
│   ├── CMakeLists.txt          # main 组件注册
│   ├── Kconfig.projbuild       # menuconfig 自定义选项（引脚、MQTT等）
│   ├── app_main.c              # 入口: app_main() + FreeRTOS 主循环任务
│   ├── config.h                # 引脚/常量/协议定义 (纯 C)
│   ├── mqtt_ca_cert.h          # TLS CA 证书 (原样复用)
│   ├── state_machine.c/h       # 主状态机 (从 main.cpp 拆出)
│   ├── uart_protocol.c/h       # UART 帧协议 (uart_driver)
│   ├── mqtt_handler.c/h        # esp_mqtt 客户端
│   ├── mqtt_ota_handler.c/h    # MQTT OTA 处理
│   ├── arm_ota.c/h             # ARM IAP 状态机
│   ├── ota_manager.c/h         # ESP OTA (esp_ota API)
│   ├── nvs_storage.c/h         # NVS 键值存储
│   ├── offline_cache.c/h       # 离线缓存 (循环缓冲区重写)
│   ├── led_status.c/h          # LED 驱动 (LEDC)
│   ├── tcp_provision.c/h       # HTTP 配网 (lwIP socket)
│   └── sn_encoder.c/h          # SN 编码 (纯 C, 直接复制)
└── components/
    └── smartconfig/             # ESP-Touch SmartConfig
        ├── CMakeLists.txt
        ├── smartconfig_manager.h
        └── smartconfig_manager.c
```

## 2. API 映射摘要

| 功能 | Arduino | ESP-IDF |
|------|---------|---------|
| 入口 | `setup()`/`loop()` | `app_main()` + FreeRTOS 任务 |
| 时间 | `millis()` | `esp_timer_get_time()/1000` |
| 延时 | `delay(ms)` | `vTaskDelay(pdMS_TO_TICKS(ms))` |
| 日志 | `Serial.printf()` | `ESP_LOGI(TAG, ...)` |
| 重启 | `ESP.restart()` | `esp_restart()` |
| UART | `Serial1.begin/read/write` | `uart_driver_install/read_bytes/write_bytes` |
| WiFi | `WiFi.begin/softAP/status` | `esp_wifi_*` + 事件驱动 |
| MQTT | `PubSubClient` | `esp_mqtt_client` (事件驱动，无需loop) |
| NVS | `Preferences` | `nvs_open/get_str/set_str` |
| HTTP | `HTTPClient` | `esp_http_client` |
| OTA | `Update` | `esp_ota_begin/write/end` |
| TCP | `WiFiServer/WiFiClient` | lwIP `socket/bind/listen/accept` |
| JSON | `ArduinoJson` | `cJSON` |
| LED PWM | `ledcWrite` | `ledc_set_duty` (C2 只有 LOW_SPEED) |
| SmartConfig | `WiFi.beginSmartConfig` | `esp_smartconfig` |
| NTP | `configTime` | `esp_sntp_*` |

## 3. Bug 修复清单（移植时一并修复）

| # | 问题 | 位置 | 修复方案 |
|---|------|------|----------|
| 1 | offline_cache `remove_item_at()` O(n) shift | offline_cache.cpp:214 | 重写为循环缓冲区，head/tail 指针 O(1) |
| 2 | offline_cache JSON 无转义 | offline_cache.cpp:131 | 用 cJSON 构建序列化 |
| 3 | MQTT TLS `setInsecure()` 跳过验证 | mqtt_handler.cpp:124 | 使用 CA 证书验证 |
| 4 | arm_ota 8KB 静态缓冲区 | arm_ota.cpp:45 | 降至 4KB |
| 5 | WiFi 重连阻塞 delay() | main.cpp:353 | 改为事件驱动 |
| 6 | tcp_provision Arduino String 堆碎片 | tcp_provision.cpp 全文 | 改为 snprintf + 固定缓冲区 |
| 7 | ARM OTA 256KB malloc 到 RAM | ota_manager.cpp:368 | 改用 arm_ota_feed() 流式模式 |

## 4. 内存优化（C2 272KB SRAM）

- arm_ota stream buffer: 8KB → 4KB
- offline_cache: 1000 条 → 500 条
- mqtt_ota buffer: 4096 → 2048
- tcp_provision: 4 slot → 2 slot
- ARM OTA 下载: 256KB malloc → 流式
- HTML 模板: 分段 write()，不拼接 String

---

## 5. 转换顺序

```
阶段 1: sn_encoder.c (直接复制), config.h, nvs_storage.c, led_status.c
阶段 2: uart_protocol.c, mqtt_handler.c
阶段 3: mqtt_ota_handler.c, arm_ota.c, ota_manager.c
阶段 4: offline_cache.c, tcp_provision.c, SmartConfigManager
阶段 5: state_machine.c, app_main.c (集成)
```
