# 深浅主题、中文和像素字体实施计划

**目标：** 在现有独立 ESP32-C3 工程实现可保存的中英文、深浅主题，并替换电脑栅格字体。

**架构：** 保留业务与通信状态机。字体模块采用原生 ASCII8×16/CJK16×16 单色点阵及原生12×24数字，UTF8解码与文字测量共享。翻译表独立，RGB565主题由场景传入。外观设置使用独立NVS键，不占用DSP的84项参数。

**技术：** ESP-IDF5.5.4，条带RGB565绘制，GNU Unifont子集，C主机验证。

文件职责：字体代理负责gfx/font/字库工具；翻译代理负责locale及翻译测试；场景代理负责深浅配色/中文布局/同源截图；主代理负责状态机/持久化/工程整合/发布。

- [ ] 新字体UTF8、原生字形、缺字回退、中文覆盖、宽度和条带一致性验证。
- [ ] 全菜单、84参数、状态/告警/帮助/提示中文翻译，保留单位和设备标识。
- [ ] 双主题对比度、中文布局和外观设置场景，实际绘图截图。
- [ ] 外观设置实时预览；保存成功后冷启动恢复；取消恢复已保存设置；保存失败不伪报成功。NVS损坏值归一化。
- [ ] 主题不使用显示反色命令；现有A/B诊断保留独立入口，退出恢复默认。
- [ ] 主机行为/字库/多语言多主题布局检查，ESP-IDF编译与4MB镜像分段/哈希校验。实机刷新/声音/光学效果仍需用户验证。

WHEN进入外观设置 THEN可以切换深浅/中英文即时预览；WHEN保存失败 THEN保留提示和可重试状态；WHEN取消 THEN恢复保存的主题/语言。

禁止覆盖其它工程、自动烧录或提交无关更改。完整镜像烧录会覆盖本地配置，另提供app文件用于既有匹配分区升级。
