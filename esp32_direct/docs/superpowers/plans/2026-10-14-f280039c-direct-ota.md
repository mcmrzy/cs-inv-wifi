# F280039C direct OTA implementation plan

User-approved protocol: ESP32 UART0 -> DSP SCI-B at 115200 8N1; no ARM forwarding.
Reuse the current MQTT/BLE staging, hash verification, UART owner and status path.

- [x] Inspect current service/owner and original ARM-to-DSP protocol.
- [x] Read actual dsp_ota.c/h from docs/esp32. The supplied files define LB
  and magic-high checks only; do not guess other header fields or claim CRC32.
- [x] Implement and test a DSP-specific transport with one 1029-byte packet
  buffer; CMD42 -> HR; erase ACK 3s/5 attempts; erase complete CR 12s/5 waits;
  up-to-1024-byte payload with actual source's short tail, wrapped word address and high-first Modbus CRC;
  data ACK 3s/10 attempts; successful EOT -> wait 1 second.
- [x] Validate packed image before CMD42 using actual source LB/magic-high,
  min/even length and conservative capacity. No invented full-header CRC.
- [x] Submit both reset/Boot probe and flash jobs to the existing UART owner.
  Hold normal DSP polling while in Boot; resume only after exit/transfer.
  No USB/MQTT task may access UART directly.
- [x] Route DSP staged images through the new core; retain BMS transport.
  Keep success wording distinct from unimplemented App version readback.
- [x] Run actual owner/service integration tests and complete host regressions.
- [x] Build and package an isolated source snapshot with current mutex repair.

Cases: successful complete transfer; invalid header causes zero UART output;
early/partial replies; HR repeated before CR; missed ACK repeats identical
packet/address; erase/data retry exhaustion; cancellation; failed send/read;
UART job exclusivity; pending parameter writes; restore synchronization;
full-capacity image/address wrap; oversize rejection; no false App-run claim.

DSP side requirement: existing CMD42 handler must safely stop power control,
write the Boot-specific RAM request flag and transfer to the Boot entry using
the DSP compiler's supported startup sequence. This ESP project cannot write
DSP RAM directly; confirm actual DSP implementation before runtime claims.
