# UI v0.5.0 Implementation Plan

> For agentic workers: use subagent-driven-development with isolated file ownership, followed by integration review.

**Goal:** Deliver the approved colorful 320x240 UI and predictable six-key interaction as a manually flashable ESP32-C3 image.

**Architecture:** Retain DSP/BMS protocols, parameter indexes and strip rendering. Separate navigation/editor state from scene drawing and physical key decoding. Preserve fixed identity H1ZZX0013900001P.

**Tech Stack:** ESP-IDF 5.5.4, C, RGB565 SPI DMA, static Noto glyph subset, Windows host C tests.

## Chunk 1: Interaction and rendering

- [x] Replace sixteen top-level entries with six groups and submenus; retain all previous destinations and 84 advanced parameters (`direct_ui.c/h`).
- [x] Add UI_REVIEW, draft/current distinction, submission revalidation, failure draft retention and duplicate-write blocking. Test state transitions, parameter boundaries and offline/readonly cases (`tests/ui_v050_test.c`).
- [x] Emit confirm/back only on press, directions repeat; beep only first press. Preserve BS818A quiet interval and frame validity (`direct_key_codec.c/h`, `direct_keys.c`, `tests/key_codec_test.c`).
- [x] Draw approved menu cards, full editor/review, clear footer actions, themed scenes; preserve BMS/energy/alarm/time/maintenance content (`direct_ui_scene.c`).

## Chunk 2: Integration and release

- [x] Check navigation history, all parameter reachability, hidden-combo removal, key wake and pending-write behavior.
- [x] Add Chinese translations; regenerate Noto subset. Render actual C scenes in both languages/themes, validate strip equivalence and pixel guards.
- [x] Run protocol, key, UI, energy, locale, graphics and LCD transport regressions. Update superseded navigation assertions without weakening data/protection tests.
- [x] Build ESP-IDF with `build.ps1`; increment version to 0.5.0-direct-ui. Check flash partition capacity.
- [x] Merge four segments into exactly 4194304 bytes; compare segments and FF padding, generate SHA256 and burning instructions. No automatic flashing.
- [x] Provide actual renderer screenshots and document remaining physical validation: responsiveness, SPI display, held-key behavior and DSP acknowledgement.

## Review gates

Spec review: every old function remains reachable; hardware pins, protocols, fixed SN and protection policy remain preserved.
Quality review: bounded indexes and queue semantics, no stale-data success, no overlapping text/units, no full framebuffer allocation. Release does not claim physical acceptance.

## Execution evidence

Host tests passed; 212 C scenes checked; ESP-IDF final build 0x1652F0; merged exactly 4194304 bytes with identical segments and FF padding. Manual spec and independent quality review found stale diagnostic measurements, missing status-only fault wake, duplicate BMS detail and missing NVS reset failure feedback; all repaired and checked. Physical acceptance remains pending.
