# Logo 停留与离线蓝牙诊断固件

版本：`0.6.41-startup-diag`，ESP32-C3 / ESP-IDF 5.5.4，Device 身份配置。

## 已确认的问题与改动

用户提供的日志运行 `0.6.40-remote-control`，ELF 摘要前缀 `c7f04ba22` 与本地原发布产物匹配。DSP 持续回复，Wi-Fi 曾获得 IP；日志里的重启由用户手动操作，不能作为自动复位证据。

原状态机在已有 Wi-Fi 配置、MQTT 一直未连接时没有自动开放 BLE 的分支。新回归先在原实现中失败，再在修复后通过。

- 云端未连接满 30 秒后，等待已准入的 MQTT 握手结束、OTA 排他占用解除、在途补传退出，再释放 MQTT 内存并开放本地 BLE。
- 手机未连接时提供至少 15 秒的本地访问机会，然后恢复云端尝试；持续离线时重复窗口。手机已连接或正在配网时保留本地访问，不主动断开手机。
- MQTT 已连接时沿用原有 MQTT/BLE 常驻逻辑。30 秒是调度窗口，不是对在途网络操作的强制取消时限，也不是实际广播就绪的保证；实际广播以 `BLE actual ready; advertising:` 为准。

Logo 的硬件故障根因尚未确认。本轮增加定位证据，没有修改 LCD 引脚、SPI 频率、屏幕初始化参数，也没有宣称 Logo 故障已解决：

- 启动阶段以 WARN 输出：显示任务开始、本地设置读取完成、Logo 开始/保持/淡出/完成、进入刷新循环、首次界面开始/完成及 `ok`。
- 主循环观察显示任务，输出 `LCD_DIAG`。新增少量原子状态，不创建诊断任务或额外显示缓冲。
- 首帧未完成或显示异常时每 5 秒报告，软件状态正常时每 30 秒报告。观察器依赖主循环继续运行；它不能替代物理 LCD 验收。

## 读取日志

刷入后，保存从开机起至少 90 秒的完整串口输出，采集期间不要手动重启，并观察蓝牙扫描结果。

关键字段：

| 日志/字段 | 含义 |
| --- | --- |
| `LCD_BOOT_SPLASH hold`、`fade_out`、`frames=...` | Logo 动画是否到达保持、淡出和返回阶段 |
| `LCD_UI_FIRST_FRAME begin/done` | 首次主界面是否进入、返回；`ok` 为软件传输结果 |
| `stage`、`stage_age` | 当前显示阶段及停留毫秒数；持续增长可定位卡点 |
| `first`、`loop_age` | 首次绘制调用是否返回、距最近刷新循环的毫秒数 |
| `spi`、`spi_age`、`bytes`、`row` | 当前传输是否在途、持续时间、字节数及显示条带行号 |
| `tx`、`errors` | 已返回的传输次数与驱动返回的错误数 |
| `stack_free` | 显示任务启动/首次界面完成时采样的最低剩余栈；不是持续采样值 |
| `Local BLE mode: MQTT released` | 已为本地恢复释放 MQTT 资源 |
| `BLE actual ready; advertising:` | BLE 协议栈已实际启动广播 |

如果 `first=1`、`tx` 继续推进但实物仍显示 Logo，说明软件路径与物理显示结果不一致，应进一步采集屏幕总线信号；不能仅凭软件健康状态判定屏幕正常。

## 构建与验证边界

诊断版基于当前工作区，包含此前已有的 `0.6.41-battery-config` 改动；不是只包含本轮补丁的原 `0.6.40` 重编译。主工作区 `version.txt` 保持原值，通过独立源代码快照设置诊断版本。

- 新增离线窗口、手机保护、再次云端尝试、在途握手与 OTA 保护回归通过；原启动内存、MQTT/BLE 生命周期等定向回归通过。
- 实际 Logo 渲染器与显示初始化主机测试通过：双主题、借用缓冲边界、先清屏再显示、Logo 淡出。
- 显示观察器主机测试通过：显示所有者停在 Splash/SPI/快照时可报告，刷新停止可报告，健康日志节流。
- ESP-IDF 5.5.4 编译通过，镜像校验通过；App 1,638,864 字节，OTA 分区剩余 65,072 字节，静态 RAM 182,620 字节，资源预算通过。分区表与原 `0.6.40` 构建一致。
- 完整生产主机套件在远程命令测试链接时中断：`undefined reference to direct_battery_validate`。该测试只编译此前已有的命令处理源码与测试替身，本轮未改这些文件；不能报告整套套件通过。
- 未连接/刷写设备，未验证实际 BLE 广播、LCD、DSP 采用、MQTT 交付或 OTA 安装/重启。

本地产物、独立源码快照、构建日志、资源报告、改动前备份在 `tmp/startup_recovery_20261022/`；ELF 保留在 `build_startup_diag_20261022/`。
