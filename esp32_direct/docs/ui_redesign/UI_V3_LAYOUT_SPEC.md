# 页面布局细化

日期：2026-10-08。状态：已完成静态设计和原像素检查，未接入ESP固件。

## 用户确认及修订

采用黑底。逆变器位于中央，PV上、市电左、负载右、电池下；连接横平竖直，不能斜线或折线。发电机及辅助数据移到其他页面。用户授权进一步自行研究美观布局。

## 统一尺度

320×240；左右内容边距12–16像素。标题基线18，分隔27；底部分隔221，提示基线235。正文只占28–220区域。主体字13–14，重要值19–29，辅助值11–12，密集表格索引9–10。大数字与单位分层，但基线一致；数值采用等宽数字特性。小字体是否采用需最终ESP字体资源对应验证。

颜色延续第二版，黑底与灰分隔线；绿色用于活动路径/已确认结果，蓝色市电/最低单体，琥珀PV/警告/最高单体，红色故障。必须同时有图标或文字，不能只凭颜色判断。

主屏左设备中心x40，中央x160，右设备中心x280，左右距中央各120像素；水平路径y124，上下路径x160。输入/输出功率基线166。中央设备图标略大，外围线条图标保持一致线宽，留出线路端点间隙。SOC与电压分层，主屏不再放发电机、温度、频率和负载比例。

## 六类页面与操作状态

| 页面 | 版式与重点 | 状态行为 |
|---|---|---|
| 主屏 | 四方向图标、正交流线、功率与SOC；通信与时间在顶栏 | 充/放电箭头由DSP状态驱动，未知路径灰色；告警状态必须能进入告警页 |
| 设置列表 | 每行一个参数；名称左、值右；焦点用底色+左侧标识 | 浏览与编辑分开；只读字段不显示可修改反馈 |
| 参数编辑 | 单参数大数值、左右修改提示、明确未保存 | 回读确认才显示保存成功；发送中/超时/拒绝必须单独状态，ESC取消草稿 |
| 运行参数 | 电压/频率/电流/负载/温度5行，固定数值列 | 输入/输出/电池/系统分组分页；未知为--，过期不能显示Updated just now |
| BMS | SOC/总压/差值+4×4单体，最高最低位置标记 | 在线显示一致快照；离线整页隐藏实时格，明确最后更新时间 |
| 告警 | 当前问题优先，选中告警与简要原因，ENTER查看详情 | 无告警、警告、故障分别呈现；长文本详情分页，不裁切关键原因 |
| 发电机 | 独立设备详情，运行状态和当前AC输入来源 | 只呈现可证实数据；独立功率/电量无字段则--，不把共用AC功率误标为独立值 |

系统菜单总数沿用当前direct_ui.c的15入口；示例画面只显示第一页5行，并非删除其他10项。设置参数例图是Output分组样式，01/04表示分组内页示例，实际项目按条目/页数生成。保留所有参数索引、现有告警表和原单位，不因美化删掉可达数据。

## 固件实现约束

沿用独立工程和0.2.3硬件SPI候选配置，不新增GPIO。屏幕与按键提示音互不等待。绘图层读业务快照，所有DSP写入继续唯一任务执行及回读确认。

字体/图标需一次确定并生成裁剪后的资源；不能直接用Windows字体预览推断ESP已有字库。LVGL或轻量绘制都可承载同样版式，最终选择以运行内存、传输速度和代码维护成本为依据。主屏数字更新只重绘对应区域；小面积流向动画在基础帧/按键/网络稳定后验证。
