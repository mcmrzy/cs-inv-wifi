当前操作

这版保留什么

光伏、市电、负载、电池四向布局；原84项参数及范围；DSP回读确认；BMS与单体数据；告警；发电机信息；主题、语言、时间、设备信息和恢复设置。

未确认的数据不显示成正常值；不编造发电机功率或能量；离线和只读参数锁定写入。

变化在哪里

四个常用页直接切换；六个设置组；返回保留当前位置；当前值与草稿分开；保存前复核、保存后确认；明确失败和重试。

浅深双色保留，无灰色常规配色。图标、色带和文字共同标识状态。
