# DSP 通信完善与联调说明

日期：2026-10-14。联调固件版本：`0.6.7-dsp-dev`。

## 已完成

- DSP UART0，TX=GPIO1、RX=GPIO0，115200 8N1。
- 依据 App(10) 每 110ms 的发送时隙查询；串口读取调度会带来少量时间差。没有新鲜 BMS 数据时循环 `03/04`，有数据时循环 `03/04/05/06`。绝不把无效 BMS 数据当作零值发送给 DSP。
- 保留同一个 DSP UART owner 串行处理参数写入、轮询和升级静默，写入仍要求 `25` 回读匹配；本次没有开放 DSP/BMS OTA。
- 接收器采用有界 128B 缓冲，不分配堆内存。支持任意分包、连续帧，检查声明长度与 CRC16；坏长度、CRC 和超时后重同步。未完成帧在超时前不扫描内部帧头，避免合法数据里偶然出现短帧时误拆。
- `03` 更新故障、三组状态、三组告警和模式；`04` 更新完整 32 个运行量并记录自己的新鲜度；`25` 更新有协议依据的配置。合法零值保持零；负电流、负功率、负温度保留符号。仅状态帧或配置帧不会把过期运行量重新标记为有效。
- `04` 接受 CRC/长度均正确且至少 69B 的帧，只解析已确认的 69B 前缀。71B 兼容测试并不代表当前 DSP 实际发送71B，需日志确认实际长度。
- release 显示 DSP 初始化、首次在线/失联，以及每30秒的收发计数与限长原始数据。USB 输入 `status` 可随时查看 `[DSP]` 与新鲜数据下的 `[DSP_DATA]`。
- MQTT 连接和 `query_info` 不再等待不存在的 ARM 信息读取。上报 ESP 的真实 SN/固件与产品信息，DSP/ARM 版本、未取得的额定值及电池结构用 `null`，不使用硬编码的版本/容量或假电池化学类型。
- 心跳仍遵循已有180秒周期及显式查询/调试周期，只发布2秒内的真实 `04` 快照。

## 日志判读

| 观察 | 说明 |
|---|---|
| `tx` 增加、`rx_bytes=0` | ESP 发出查询，UART没有收到字节；检查DSP供电、连接方向、电平、共地及DSP运行状态 |
| `rx_bytes` 增加、`frames=0` | 收到字节但没有完整校验有效帧；对照 `crc/len/timeout` 和 `DSP RX prefix` 判断 |
| `frames` 增加、`rejected` 增加 | CRC有效，但已知命令的有效数据布局不够长或快照写入失败 |
| `03` 增加、`04=0` | 状态回复正常，但没有有效运行量，不能宣称测量在线 |
| `DSP link=ONLINE`、`04` 增加 | 已接收真实且新鲜的运行数据，检查 `DSP data raw` 与设备显示 |
| `DSP parameter sync requested` | DSP 请求旧 ARM 的 `00/01/02` 持久配置；当前缺少可靠完整设置，未发送猜测配置 |
| `unknown` 增加 | 收到现有代码没有依据的命令，保留命令码、长度和限长原始数据用于补协议 |

`age04_ms=4294967295` 表示从未收到测量，不能当作真实持续时间。日志中的 `dV/dA/dC` 分别表示0.1V、0.1A、0.1℃；电网/输出电压是1V，功率是1W。

## 有依据的协议边界

只读原始来源：

- `App(10)/App/source/ComDSP/UsartDsp.c:235-315`：03/04字段；`610-620,931-976`：轮询及单发送互斥。
- `UsartDsp.c:226-233,68-179`：DSP主动请求00/01/02及旧ARM配置回包。
- `APP/gd32f10x_it.c:111-119`：声明长度+4；`UsartDsp.c:535-536`：Modbus CRC低字节在前。
- `Collector/Collector.c:1175-1203`：旧信息字段包含硬编码，不能视为DSP真实查询。

现有源码没有DSP版本/型号/硬件版本/额定值的真实读取命令；`arm_poll_request_info()` 兼容钩子不会编造一个新命令。完整00/01/02回包需要原ARM持久设置和字段来源，当前只诊断请求，不用默认值覆盖DSP。额外收到的有效尾部字段也不会被猜作版本。

## 验证及固件

新增测试覆盖：全部32字段及符号、合法零、短/错CRC帧、扩展帧；任意分包、连帧、噪声、内部伪帧头和超时；提取实际DSP任务的UART对话、真实03/04/25状态应用、BMS有效性、I/O失败、静默及OTA独占；真实info JSON和无ARM时的连接/查询上报。

`tmp/dsp_v067_source` 是本次独立构建副本，保留复制当时已有的配网开发改动。共享目录的版本号、配网源码与另一聊天的构建没有被回退或覆盖。联调包不是DSP全功能/完整参数同步/直连OTA验收声明。

设备应用更新使用包内 `device/app.bin`，保留SN和配网；整片4MB镜像会覆盖NVS及factory身份。更新后先确认版本，再采集DSP摘要、`status`和MQTT TLS日志。应逐字段对照真实DSP与原ARM显示，检查掉线恢复和重连内存；尚未烧录或做这些实机验收。
