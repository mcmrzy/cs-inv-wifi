# T280C7-C12-26 IPS 屏幕驱动与接线

规格书第 4 页确认该模组为 2.8 英寸 IPS TFT、Normally Black、240×320、ST7789、4 线 SPI，无触摸。固件以 320×240 横屏显示。

## 12 针 FPC

按规格书第 5、7、8 页的脚号接线。旧 SP-TFT028F276 使用 14 针排线，更换时按信号重新转接。

| 新屏 FPC 脚号 | 信号 | L10 直连板接法 |
| ---: | --- | --- |
| 1、8、12 | GND | 共地 |
| 2 | RESX | GPIO10，低有效复位 |
| 3 | SDA | GPIO7，SPI MOSI |
| 4 | SCL | GPIO6，SPI 时钟 |
| 5 | CSX | 低有效，沿用原板硬件拉低 |
| 6 | DCX | GPIO9，低电平为命令，高电平为数据 |
| 7 | TE | 帧同步输出，当前驱动未使用 |
| 9 | VDD | 屏幕电源，规格书工作范围 2.4～3.3 V |
| 10 | LED-A | 背光正极，接背光驱动 |
| 11 | LED-K | 背光负极，接背光驱动 |

规格书第 6、7 页给出背光典型正向电压 3.0 V、典型电流 80 mA，建议独立恒流驱动。

## 固件初始化

| 项目 | 当前设置 |
| --- | --- |
| `MADCTL`（`0x36`） | `0x70`，RGB 色序，保留横屏方向 |
| `COLMOD`（`0x3A`） | `0x55`，16 位 RGB565 |
| 显示反转 | `INVON`（`0x21`），正常启动和屏幕恢复时启用 |
| 电源与 Gamma | 按 IPS 例程写入 `B7=55`、`BB=1A`、`C3=19` 和 `E0/E1` 两组 Gamma，在 `SLPOUT` 前完成 |
| 设备信息 → LCD 测试 | A 发送 `INVOFF`，B 使用 `INVON`，退出恢复 `INVON` |

实机已确认 `INVON` 修正了反色。随附 ST7789P3 例程使用 RGB 色序和竖屏窗口。L10 保留横屏方向及渲染器动态设置的窗口，首帧写完后开启显示。

例程在完整的 `D0 A4 A1` 前还有一笔单参数 `D0 A7`。ST7789P3 手册将 `D0` 定义为两个参数，固件采用完整的 `D0 A4 A1`。显示观感和亮度待上板验证。
