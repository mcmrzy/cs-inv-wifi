## 一、产品介绍

### 1.1 产品定位

CS-I10-6k2 是一款面向**无电网地区**用户的 48V 单相离网逆变器，适用于家庭、偏远基站、牧区、岛屿等无市电场景。用户通过太阳能光伏板发电，经逆变器转换后供家用电器使用，多余电量存入 48V 锂电池组。

### 1.2 系统组成

```
    ☀ 光伏板                       🏠 家用负载
     (1500W)                      (电视/冰箱/灯/水泵)
       │                                │
       ▼                                ▲
┌──────────────┐                 ┌──────────────┐
│    MPPT      │──── DC ────────→│   逆变器     │── AC 220V ──→
│  太阳能充电   │                 │  DC→AC 变换   │
└──────────────┘                 └──────┬───────┘
                                        │
                                        │ DC 48V
                                        ▼
                                 ┌──────────────┐
                                 │   电池组      │
                                 │ 16S LiFePO4  │
                                 │ 含 BMS 保护板  │
                                 └──────────────┘

         ESP32-C3 (WiFi)
         ┌──────────┐
         │  MQTT    │──── 4G/WiFi ───→  云端服务器 ──→  APP
         │ 网关     │
         └──────────┘
```

### 1.3 核心参数

| 参数 | 值 |
|------|-----|
| 型号 | CS-I10-6k2 |
| 额定功率 | 6200W |
| 输出电压 | 220V / 50Hz（单相） |
| 电池电压 | 48V（16 串 LiFePO4） |
| MPPT 电压 | 60~150V |
| 通信方式 | ESP32-C3 WiFi / MQTT |
| IP 定位 | WiFi 连接后自动获取城市 |

### 1.4 核心功能

| 功能 | 说明 |
|------|------|
| 光伏充电 | 太阳能板通过 MPPT 给电池充电 |
| 逆变供电 | 将电池 48V DC 转为 220V AC 供负载使用 |
| BMS 保护 | 过压/欠压/过流/过温/短路多级保护 |
| 远程监控 | 手机 APP 实时查看运行数据 |
| 远程控制 | 开关机、参数设定、充放电控制 |
| 故障告警 | 异常事件实时推送到手机 |

### 1.5 与并网逆变器的关键区别

| 对比项 | 并网逆变器 | 本产品（离网） |
|--------|-----------|---------------|
| 电网依赖 | 必须有电网 | **无电网独立运行** |
| 频率来源 | 跟随电网 | **逆变器自己产生** |
| 电池 | 可选 | **必须有电池** |
| 光伏用途 | 优先卖给电网 | **充电+供负载** |
| 使用场景 | 城市家庭 | 偏远地区/无电网 |

## 二、用户画像与使用场景

### 2.1 主要用户群体

| 用户类型 | 特点 | 核心关注 |
|---------|------|---------|
| **家庭用户** | 居住在无电网山区/牧区/岛屿，日常用电依赖太阳能 | 能不能正常供电、还剩多少电、还要多久充满 |
| **商业用户** | 农家乐、基站、收费站、监控站 | 设备是否稳定、故障时能否及时知道 |
| **运维人员** | 安装商/代理商，管理多台设备 | 哪些设备在线、哪些有故障、远程诊断 |
| **家庭成员** | 老人的子女远程帮忙照看 | 家里停电没有、老人操作是否正确 |

### 2.2 典型使用场景

**场景 1：日常查看**
> 张先生在山区老家，每天早上打开 APP 看看电池还有多少电、昨天发了多少电，决定今天能不能用大功率电器。

**场景 2：异常处理**
> 李女士在城里上班，收到 APP 推送"老家设备过压保护"，立刻打开 APP 查看详情，发现是第 5 节电池电压过高，远程关闭充电，联系安装商上门检查。

**场景 3：设备安装**
> 王师傅是安装商，给客户装完设备后，打开 APP 绑定设备 SN，确认数据正常上报，设置好充放电参数后交付客户。

**场景 4：多设备管理**
> 某代理商旗下有 50 台设备分布在 3 个省份，每天打开 APP 看总览：48 台在线、2 台离线，本月总发电 12500 kWh。

## 三、核心需求分析

### 3.1 用户最关心的 5 个问题

| 排名 | 用户问题 | APP 怎么回答 |
|------|---------|-------------|
| 1 | **有没有电** | 首页大字显示当前 AC 输出功率 |
| 2 | **还剩多少电** | 电池 SOC 环形图 + 剩余充放电时间估算 |
| 3 | **今天发了多少电** | 今日发电量卡片 |
| 4 | **设备有没有问题** | 首页设备状态标签 + 红点告警 |
| 5 | **能不能远程开关** | 一键开关机按钮 |

### 3.2 功能优先级

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 必须 | 设备数据查看（AC/电池/PV 核心参数） | 用户打开 APP 就能看到 |
| P0 必须 | 告警推送通知 | 设备出问题用户立刻知道 |
| P1 重要 | 远程开关机 | 常用操作 |
| P1 重要 | 能量统计 | 日/月/年统计 |
| P2 增强 | BMS 参数设置 | 进阶用户/安装商 |
| P2 增强 | 电芯详情 | 诊断电池健康 |
| P3 运维 | 固件 OTA | 远程升级 |

### 3.3 数据优先级

APP 收到 MQTT 数据后，各主题的更新频率和对用户可见性的优先级：

| 主题 | 频率 | 用户可见 |
|------|------|---------|
| `data/ac` | 5s | ✅ 首页核心 |
| `data/battery` | 5s | ✅ 首页核心 |
| `data/pv` | 5s | ✅ 首页核心 |
| `data/status` | 5s | ✅ 状态标签 |
| `data/energy` | 60s | ✅ 能量页 |
| `data/cells` | 30s | ⚠️ 仅电芯详情页 |
| `data/alarm` | 事件 | ✅ 立刻推送 |

## 五、关键操作流程

### 5.1 设备绑定流程

```
开始
  │
  ▼
用户打开 APP → 注册/登录
  │
  ▼
点击"添加设备"
  │
  ├──→ 方式1: 扫描设备二维码（设备外壳贴纸）
  │      │
  │      ▼
  │    识别 SN → 填入 SN
  │
  ├──→ 方式2: 手动输入 16 位 SN
  │
  ▼
输入设备名称（可选，默认型号）
  │
  ▼
绑定成功 →
  │
  ▼
等待设备上线（WiFi 连接）
  │
  ├──→ 在线: 进入设备详情页，开始查看数据
  │
  └──→ 离线: 显示"等待设备上线"，引导用户检查 WiFi
```

### 5.2 日常查看流程

```
用户打开 APP
  │
  ▼
设备列表页
  │
  ├─ 看到每台设备的 3 个核心数字:
  │  AC功率 | 电池SOC | 光伏功率
  │
  ├─ 设备在线 → 绿色圆点  → 点击进入详情
  ├─ 设备离线 → 灰色圆点  → 显示最后在线时间
  └─ 设备故障 → 红色圆点  → 点击进入详情 + 查看告警
```

### 5.3 告警处理流程

```
设备产生告警 → 云端收到 MQTT → APP 收到推送通知
                                    │
                                    ▼
                              用户点击通知 → 告警详情页
                                    │
                                    ├→ 查看故障原因（如: Cell 5 过压 3.65V）
                                    ├→ 故障解决建议
                                    └→ [远程关闭充电] 按钮（一键操作）
```

### 5.4 远程设置流程

```
用户进入设备设置页 → 调整参数（如充电电流 50A→80A）
  │
  ▼
弹出确认框: "确定将充电电流设为 80A？"
  │
  ├── [取消]
  └── [确定] → APP 发送 MQTT 命令 → 等待设备回复（超时 5 秒）
                  │
                  ├── ✓ ok → 显示"设置成功"
                  ├── ✗ error → 显示错误原因
                  └── 超时 → "设备无响应"
```

### 5.5 开关机流程

```
设备概览页 → 点击电源按钮
  │
  ▼
确认弹窗: "确定要关闭交流输出吗？关闭后设备停止供电。"
  │
  └── [确定关闭] → 发送 MQTT → 收到 ok → 状态变为"已关机"
```

### 5.6 首次配网流程（安装场景）

```
设备上电（未配网）→ ESP32 启动 AP 热点 CS_INV_XXXXXX
  │
  ▼
安装人员手机连接热点 → 配网页面填入 WiFi + MQTT Broker
  │
  ▼
ESP32 连接 WiFi → 连接 MQTT → 上报设备信息 + IP 定位
  │
  ▼
APP 设备变绿色，开始显示数据
```

## 六、全局 UI 规范

### 6.1 配色方案

| 用途 | 色值 | 场景 |
|------|------|------|
| 主色 | `#2E7D32` 绿色 | 按钮、标题、充电/发电状态 |
| 辅色 | `#FF6F00` 橙色 | 放电状态、警告、电池 SOC 中段 |
| 危险色 | `#E53935` 红色 | 故障、告警、保护触发 |
| 离线色 | `#9E9E9E` 灰色 | 设备离线 |
| 背景色 | `#F5F5F5` 浅灰 | 页面背景 |
| 卡片色 | `#FFFFFF` 白色 | 数据卡片 |
| 文字主色 | `#212121` 深灰 | 主要文字 |
| 文字辅色 | `#757575` 中灰 | 次要文字、标签 |

### 6.2 字体规范

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 28sp | Bold | 页面标题、核心功率值 |
| H2 | 22sp | Medium | 区块标题、SOC 百分比 |
| H3 | 18sp | Medium | 卡片标题 |
| Body | 16sp | Regular | 数据值、列表项 |
| Caption | 14sp | Regular | 单位、标签、副文字 |
| Small | 12sp | Regular | 时间戳、次要说明 |

### 6.3 数据刷新

- 实时数据（AC/电池/PV/状态）：每 5s 通过 WebSocket 推送
- 能量统计：每 60s
- 电芯数据：每 30s
- 设备在线状态：每 60s 心跳

### 6.4 通用组件

| 组件 | 说明 |
|------|------|
| 状态指示圆点 | 在线=绿，离线=灰，故障=红，告警=橙 |
| 环形进度 | 用于 SOC、效率、负载率 |
| 趋势箭头 | ↑ 上升(绿)，↓ 下降(红)，→ 持平(灰) |
| 数据卡片 | 白底圆角阴影，包含数值+单位+标签 |
| 操作确认弹窗 | 开关机/参数设置等敏感操作需要二次确认 |

### 6.5 交互规范

| 操作 | 要求 |
|------|------|
| 开关机 | 必须二次确认弹窗 |
| 参数设置 | 必须二次确认弹窗 |
| 恢复出厂 | 必须二次确认 + 输入验证码 |
| 命令超时 | 5 秒无回复提示"设备无响应"，可重试 |
| 数据加载 | 首次加载显示骨架屏，刷新时保留旧数据 |
| 下拉刷新 | 支持手动下拉刷新全部数据 |
| 离线提示 | 设备离线时显示灰色遮罩 + "设备离线" |

### 8.2 能量流向图设计

```
     光伏 ☀                          负载 🏠
      ↓ 1.07kW                       ↑ 1.87kW
  ┌─────────┐                   ┌─────────┐
  │  MPPT   │ ─────────────────→│  逆变器  │
  └─────────┘                   └─────────┘
                                    ↕
                              ┌─────────┐
                              │  电池 🔋│
                              │ SOC 78% │  ← 充/放电动画
                              └─────────┘

  → 实线 = 有功率流动 (动画流速=功率大小)
  → 虚线 = 当前无功率
```

- PV 发电 > 负载：多余电量充入电池（充电绿色动画）
- PV 发电 < 负载：电池补足缺口（放电橙色动画）
- 无 PV 时：纯电池供电

### 8.3 状态切换

| state 值 | 显示 | 颜色 |
