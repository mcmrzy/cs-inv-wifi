# 第一颗 WS2812 独立点亮测试

ESP32-C3，版本0.1.0-led1-diag。GPIO10接第一颗WS2812的DIN。
第一颗持续红色（R=64/255，G=B=0）；串联的第二、第三颗发送全零，保持熄灭。
每秒重发相同数据，灯保持常亮；串口每5帧报告一次发送状态。

采用20MHz RMT、800kbit/s、GRB/MSB优先、300us低电平锁存。
一次共72个数据符号，连同锁存和结束符放入96字硬件内存。
不初始化屏幕、按键、逆变器/BMS串口、Wi-Fi、BLE、MQTT和NVS。

分区表与现有CS-MB-PANEL相同。USB烧录测试程序会替换正常应用，测试后需刷回0.2.7正常固件。
提供的分段烧录脚本写入引导、分区、OTA启动选择和测试App，不擦除NVS、缓存或身份分区；不要勾选整片擦除。
App默认地址0x20000；运行槽不确定时使用分段烧录脚本，它会将OTA启动选择恢复到第一个槽。

验收：上电后第一颗应持续亮红灯，第二、第三颗熄灭。软件发送成功不代表灯珠已点亮。
若仍不亮，检查第一颗VDD、共地、DIN方向以及GPIO10到DIN的实际波形。
